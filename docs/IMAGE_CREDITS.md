# Photo credits

The demo cars use freely licensed photos from Wikimedia Commons, resized to 960 px wide. They are stored in `public/images/cars/`, and the hosted version keeps copies in its own file store. Each photo shows the same model as the listing, not the neighbour's actual car. Replace them with real photos when you go live.

All six are licensed **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/). The app shows the credit under the photo on each car's detail view.
